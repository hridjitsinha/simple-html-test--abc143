# Simple HTML Page

This project provides a single, responsive HTML page featuring a centered title "html" using Tailwind CSS for styling.

## Features

-   **Responsive Design**: Adapts seamlessly to various screen sizes.
-   **Tailwind CSS**: Utilizes a modern, utility-first CSS framework for efficient and maintainable styling.
-   **Centered Title**: The main title "html" is prominently displayed and perfectly centered on the page.

## Usage

To view this page, simply open the `index.html` file in your preferred web browser.
